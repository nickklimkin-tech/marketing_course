## Слайд 5. Зачем контент, если продукт «сложный»

> **Контент-маркетинг для цифровых продуктов — это не «посты ради постов». Это создание активов, которые привлекают, объясняют и убеждают 24/7 без участия продавца.**

### Почему цифровые продукты особенно нуждаются в контенте

| Проблема | Как решает контент |
|---|---|
| Пользователь не понимает, зачем ему продукт | Гайд «Как понять, что вам нужна CRM» |
| Конкурентов много, отличия неочевидны | Сравнение «Наша CRM vs Excel vs Битрикс» |
| Длинный цикл принятия решения | Серия из 3 статей: проблема → решение → выбор |
| Высокий порог входа | Кейс «Как компания X внедрила за 3 дня» |
| Нет бюджета на рекламу | Органический трафик из поиска и соцсетей |

### Контент как часть воронки


> 💡 **Правило:** один сильный гайд может приносить лиды 2–3 года. Это актив, а не расход.

## Слайд 7. SEO для SaaS и приложений

### Почему SEO — главный канал для цифровых продуктов

- **Интент пользователя высокий:** кто ищет «лучшая CRM для стартапа» — уже почти готов к покупке
- **Длинный цикл:** статья работает 2–3 года, в отличие от рекламы, которая останавливается с бюджетом
- **CAC стремится к нулю:** через год затраты на статью амортизированы, а трафик растёт

### 3 типа запросов в SEO для цифровых продуктов

| Тип запроса | Что ищет пользователь | Пример | Контент |
|---|---|---|---|
| **Информационный** | Хочет понять проблему | «какие бывают CRM» | Объёмный гайд, сравнение |
| **Коммерческий** | Сравнивает варианты | «лучшая CRM для онлайн-школы» | Обзор с вашим продуктом в списке |
| **Транзакционный** | Готов купить | «купить CRM с AI-скорингом» | Посадочная страница, демо |

> 💡 **Стратегия:** покрывайте информационные запросы контентом, коммерческие — посадочными, транзакционные — страницами «Купить / Попробовать».

## Слайд 8. Семантическое ядро и посадочные страницы

### Как собрать семантическое ядро (5 шагов)

| Шаг | Действие | Инструмент |
|---|---|---|
| 1. **Базовые запросы** | Запишите 10–15 слов, связанных с продуктом | Мозг, команда, клиенты |
| 2. **Расширение** | Найдите синонимы, уточнения, вопросы | Яндекс Вордстат, Google Trends, AnswerThePublic |
| 3. **Кластеризация** | Сгруппируйте по интенту: информационный / коммерческий / транзакционный | Таблица Excel / Notion |
| 4. **Приоритизация** | Оцените частотность и конкуренцию | Яндекс Вордстат, Serpstat, Ahrefs |
| 5. **Распределение** | Назначьте запросу страницу: статья, обзор, лендинг | Контент-план |

### Структура сайта под SEO


> 💡 **Правило:** одна страница — один запрос. Не пытайтесь на главной закрыть все запросы сразу.

## Слайд 11. Чек-лист «Контент, который продаёт»

- [ ] Каждая статья отвечает на конкретный запрос пользователя (не «про продукт», а «про проблему»)
- [ ] В статье есть CTA: лид-магнит, демо, подписка — не просто «спасибо за прочтение»
- [ ] SEO-оптимизация: ключевое слово в заголовке, первом абзаце, подзаголовке, URL
- [ ] Структура: заголовки H2/H3, списки, таблицы, изображения — легко сканировать
- [ ] Контент нельзя полностью сгенерировать AI за 2 минуты — есть уникальный опыт, цифры, кейсы
- [ ] Контент-план на месяц утверждён и назначены ответственные (даже если это вы сами)
- [ ] Есть канал распространения: не только «опубликовали в блоге», но и пост в соцсетях, email, репост в сообществах

## Слайд 12. Итоги и домашнее задание

### 3 главных тезиса сегодня

1. **Контент — это актив, не расход.** Хорошая статья приносит лиды годами, а не только в день публикации.
2. **SEO начинается с интента.** Не «впишем ключевое слово 10 раз», а «какой вопрос задаёт пользователь и какой ответ его удовлетворит».
3. **План без распространения — не план.** Статья без канала — это дневник. У каждого контента должен быть план продвижения.

### Домашнее задание

**Формат:** индивидуальное (30–40 мин) · **Дедлайн:** к вебинару 8 · **Где:** Google Sheets / Notion

**Задание:**

1. **Семантическое ядро (10–15 запросов).** Для вашего продукта:
   - 5 базовых слов
   - По 3 запроса к каждому (информационный, коммерческий, транзакционный)
   - Итого: 15 запросов, распределённых по интенту

2. **Контент-план на месяц (4 материала).** Заполните таблицу:
   - Тип, тема, формат, канал, ключевое слово
   - Минимум 1 SEO-статья, 1 лид-магнит, 1 кейс / сравнение

3. **1 готовый заголовок.** Напишите заголовок для SEO-статьи по формуле: «Как [решить проблему] с помощью [продукт / подход]» или «[Число] способов [достичь результата]».

4. **Проверка.** Покажите контент-план коллеге или клиенту. Спросите: «О чём из этого вы бы прочитали? Что кажется скучным?» Запишите реакцию.

> **Критерии проверки:** 15 запросов с интентом · 4 материала в плане с каналами · заголовок по формуле · есть обратная связь от ЦА.
