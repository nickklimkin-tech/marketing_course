## 🔍 Чек-лист «Аудит текущего маркетинга» (Вебинар 1)

Оцените по шкале 1 (хаос) – 5 (идеально). Сумма:
- 40–50 = готовы к масштабу
- 25–39 = пора систематизировать
- Ниже 25 = возвращаемся к базе

- [ ] **Продукт** — могу объяснить ценность одним предложением
- [ ] **Аудитория** — знаю 3 основных сегмента ЦА
- [ ] **УТП** — есть чёткое отличие от конкурентов
- [ ] **Монетизация** — понимаю, как продукт зарабатывает
- [ ] **Каналы** — знаю топ-3 канала привлечения
- [ ] **Воронка** — могу нарисовать путь от контакта до покупки
- [ ] **Метрики** — отслеживаю CAC, конверсию, retention
- [ ] **Контент** — есть регулярный контент (блог, соцсети, рассылка)
- [ ] **Технологии** — использую CRM, email, аналитику (не только Excel)
- [ ] **Команда** — есть ответственный за маркетинг

## 💡 Шаблон «УТП» (Вебинар 2)

**Формула 1.** «Единственный [категория], который [выгода] для [аудитория]»

**Формула 2.** «Для [аудитория], которым надоело [боль], мы [решение]»

**Формула 3.** «[Продукт] делает [действие] в [N] раз [прилагательное], чем [альтернатива]»

**Чек-лист сильного УТП:**
- [ ] Один конкретный сегмент
- [ ] Конкретная выгода (не «лучше»)
- [ ] Отличие от альтернативы
- [ ] Можно проверить за 5 секунд
- [ ] Вмещается в 1–2 предложения

## 📈 Шаблон «Отчёт для руководства» (Вебинар 14)

**5 слайдов:**

1. **Цель** — бизнес-задача и маркетинговая цель
2. **Что сделали** — 3 ключевых действия
3. **Результат** — CAC, LTV, ROMI, лиды/продажи (план vs факт)
4. **Выводы** — что сработало, что — нет
5. **План** — следующий период, бюджет, 3 действия

## ✅ Мастер-чеклист «Продукт готов к маркетингу»

- [ ] УТП сформулировано и проверено на 3 людях из ЦА
- [ ] 3 аватара ЦА заполнены
- [ ] Канвас стратегии заполнен (9 блоков)
- [ ] 3 тарифа спроектированы, цены обоснованы
- [ ] LTV / CAC > 1 (идеально > 3)
- [ ] Лендинг с 7 блоками, загружается за 2 секунды
- [ ] Email-цепочка onboarding настроена
- [ ] Аналитика: Метрика + цели + UTM-метки
- [ ] Медиаплан на тест составлен (2 канала, бюджет)
- [ ] 3 гипотезы по ICE сформулированы
- [ ] Подрядчики выбраны, ТЗ и KPI прописаны
